# RB Labs - Modern Website Redesign

A modern, production-ready website for RB Labs featuring AI solutions for finance.

## Features

- **Modern Design**: Clean, professional layout with smooth animations and transitions
- **Responsive**: Fully responsive design that works on all devices
- **Performance Optimized**: Fast loading with optimized assets and lazy loading
- **SEO Ready**: Proper meta tags and semantic HTML structure
- **Accessibility**: WCAG compliant with proper ARIA labels and keyboard navigation
- **Interactive Elements**: Smooth scrolling, animated cards, and engaging hover effects

## Tech Stack

- HTML5
- CSS3 (with CSS Variables and Grid/Flexbox)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Project Structure

```
rb-labs-gpt/
├── index.html          # Main HTML file
├── styles.css          # All styles with animations
├── script.js           # JavaScript for interactivity
└── README.md          # Project documentation
```

## Key Sections

1. **Hero Section**: Eye-catching introduction with animated background
2. **Products**: Three main products with hover effects
   - Robert the Swiss Banker
   - Decentralized Ecological Chatbots
   - Decentralized AI Models
3. **Services**: Predictive Analytics showcase
4. **Career**: Job opportunities and internships
5. **Blog/News**: Recent stories and achievements
6. **Contact**: Contact form and social links
7. **Newsletter**: Email subscription

## Design Features

- **Color Scheme**: Primary blue (#06438c) with gradients
- **Typography**: Inter font family for modern, clean text
- **Animations**: 
  - Fade-in effects on scroll
  - Hover animations on cards
  - Typing effect on hero title
  - Smooth parallax scrolling
  - Floating background patterns
- **Mobile Menu**: Hamburger menu for mobile devices
- **Form Handling**: Contact and newsletter forms with validation

## Performance Optimizations

- Minimal dependencies (no heavy frameworks)
- CSS animations instead of JavaScript where possible
- Debounced scroll events
- Lazy loading ready for images
- Optimized font loading
- Efficient DOM manipulation
